# Dans’EPS

Observer pour mieux danser. Application d’analyse vidéo chorégraphique en EPS pour iPad, collège et lycée.

## Déploiement
Dans Settings → Pages, sélectionner Deploy from a branch, branche main, dossier / (root), puis Save. Ouvrir https://lucasrx08.github.io/Dans-EPS/ dans Safari, puis Partager → Sur l’écran d’accueil.

## Confidentialité
Captations et observations traitées localement, sans serveur ni stockage applicatif persistant. Le cache hors connexion ne contient que les fichiers techniques. L’établissement doit valider le cadre de captation et l’usage avec son DPD. GitHub Pages peut traiter des informations techniques de connexion. Ne jamais utiliser de noms d’élèves ni importer de vidéos personnelles dans le dépôt.

## Version initiale
Prototype fonctionnel à valider sur iPad physique avant usage avec des élèves.
